# 门户操作日志详情移除 Implementation Plan

**Goal:** 删除门户操作日志的详情能力，页面只保留筛选、列表与导出。

**Scope:**

- 删除详情抽屉、详情状态、列表行点击事件与详情定位事件；
- 删除详情专用样式和详情交互标注；
- 导出标注顺延为 `POL-5`；
- 同步 PRD 与设计说明，明确列表行不提供详情入口；
- 保留日志列表字段、筛选、分页、导出和底层日志记录模型。

**Verification:**

1. 源码中不存在 `Drawer`、`activeRecord`、`portal-operation-log:open-detail` 和详情专用样式；
2. 列表行无点击交互；
3. 门户操作日志定向测试通过；
4. 项目构建通过；
5. 内嵌浏览器中点击列表行不打开抽屉，控制台无新增错误。
