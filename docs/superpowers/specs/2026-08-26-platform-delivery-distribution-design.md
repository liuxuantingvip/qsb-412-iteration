# 平台交付分布设计

## 目标

将数据概况中的平台环形图改为矩形树图，让客户直接看到各平台的实际交付分布，并容纳一级平台下数量较多的子平台。

## 展示口径

- 对外标题统一使用「平台交付分布」。
- 一级分组为客户熟悉的平台，如淘系、京东、抖音。
- 叶子节点为实际产生交付的子平台，如生意参谋、京东商智。
- 矩形面积表示交付数量，面积越大表示交付越多。
- 同一色系的深浅表示完成率，颜色越深表示完成率越高。
- 不在页面文案中强调“连接器”。

## 交互

- Hover 叶子节点时展示：一级平台、子平台、交付数量、完成率。
- 父级区域显示平台名称，子平台数量多时允许省略节点文字，但 Hover 信息保持完整。
- 使用现有取数宝 Semi DV 主题，不引入新的图表库或业务口径。

## 同步调整

- 公告列表行间距由 4px 调整为 8px。
- 保留数据完成率、今日涉及店铺两个现有板块，不调整其业务逻辑。

## 验收标准

- 页面标题显示「平台交付分布」。
- 不再出现平台交付环形图及一级平台百分比图例。
- 树图同时呈现一级平台分组和子平台节点。
- Hover 信息与 Mock 数据一致。
- 公告列表计算样式的行间距为 8px。
- 既有测试、构建、真页控制台检查通过。
