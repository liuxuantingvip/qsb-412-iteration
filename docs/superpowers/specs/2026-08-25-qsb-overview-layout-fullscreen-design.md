# 概览页布局与机器人全屏设计

## 目标

收口概览页 4 条视觉与交互批注：减少页面底部留白、限定机器人视图的全屏范围、统一固定列与时间表头高度，并修正任务标题的垂直对齐。

## 页面高度分配

- 概览页内容区动态铺满当前可视区。
- 左栏保持账户、我的资产和资源中心的现有高度，仅由“公告”吸收剩余高度。
- 右栏保持运行趋势和数据概况的现有高度，仅由“数据异常率”吸收剩余高度。
- 使用 CSS Grid 的 `minmax(..., 1fr)` 分配剩余空间，不使用 JS 测量，不为当前截图写死额外像素值。

## 机器人视图全屏

- 全屏目标为机器人排期表容器，不包含运行趋势标题、周期切换、四个指标、视图切换或超限提示。
- 全屏按钮放在机器人排期表容器右上角，普通态和全屏态均可见。
- 进入全屏时只对该容器调用 Fullscreen API；退出时保持当前滚动位置和页面筛选状态。
- 全屏容器使用白色背景和必要内边距，排期表在容器内铺满可用高度。
- Fullscreen API 失败时保留现有警告提示，不改变页面尺寸。

## 表头与任务对齐

- “机器人”固定列表头和 24 小时时间表头统一为 40px 高。
- 固定列标题和每个时间刻度均在同一表头行内垂直居中。
- 机器人列继续水平固定，时间轴继续水平滚动，不改变现有列宽和时间密度。
- 任务标题行使用 Flex 对齐“日/月/周”图标和文字，移除伪元素的负向 `vertical-align`。
- 任务块仍保持两行信息、文本截断、现有背景色和时间块宽度。

## 验收

- 在当前 2203×1320 视口下，概览页主内容延伸到可视区底部，公告和数据异常率板块增高。
- 常规页面与现有响应式断点下不出现板块重叠、溢出或额外水平滚动。
- 点击全屏后只显示机器人排期视图及其退出按钮，退出后页面状态保持。
- 机器人表头与时间表头高度一致，标题和时间垂直居中。
- 任务图标与标题文字垂直居中，标题和时间文本无裁切。
- `npm run build` 和项目现有测试通过，5178 真页无新增控制台错误。
