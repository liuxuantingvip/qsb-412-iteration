# 412 概览页面设计

## 目标

将 412「概览」组织为价值、运行、资产和交付四类信息。主区域优先展示所选周期产生的价值与运行结果；右侧窄栏展示当前资产和服务入口，不引入驾驶舱、实时监控或无业务意义的解释文案。

## 视觉原则

- 页面内容底保持白色，不使用深色或大面积灰底。
- 模块使用 16px 圆角和轻阴影，不增加描边框。
- 顶部四项核心指标仅由迷你趋势产生少量颜色晕染。
- 页面采用“主区域 + 右侧窄栏”，右侧栏宽度约占内容区 20%。
- 右侧栏上方 60% 以 2×2 展示资产，下方 40% 以两个等宽大入口展示帮助中心和需求反馈。
- 不混入实时运行或口径不清的覆盖模块。
- 沿用 Arco 图标与现有图表组件，不增加装饰性图片和口号式文案。

## 信息结构

1. 全局第一行：左侧展示“概览中心”，右侧展示全屏按钮；不展示日期选择器。
2. 主区域第一行：累计节省人力、计划取数运行次数、成功入库次数、成功入库数据量。
3. 主区域第二行：累计运行取数时长面积图，以及可切换运行时长/运行次数的每日计划运行热力图；两张卡片的标题、绘图区和 X 轴基线一致。
4. 右侧栏上方：店铺、连接器、云电脑和机器人资产；以 2×2 展示总量、已用和可用。
5. 右侧栏下方：帮助中心外链和需求反馈弹窗的两个等宽大入口。
6. 底部整行：数据类型环形占比和数据交付质量。

## 交互与响应式

- 帮助中心在新窗口打开；需求反馈在当前页弹窗打开。
- 全屏使用标题行右侧的圆形按钮，不占用右侧服务区，也不使用页面悬浮入口。
- 1080px 以下右侧栏回到主内容下方，资产项改为两列；720px 以下改为单列。

## 验收

- 页面不出现“驾驶舱”概念或无业务意义的解释元信息。
- 右侧资产与服务栏不随统计周期变化，价值、运行和交付数据随周期变化。
- 右侧栏宽度约 20%；资产区和服务区高度比例为 60:40。
- 页面按当前固定周期展示数据但不提供日期切换；两张运行图卡等高且 X 轴月份基线对齐。
- 累计运行取数时长趋势单调递增。
- 1100px 视口无横向溢出。
- 构建、现有自动化测试和浏览器控制台检查通过。

## 批注收口：全局栏、右栏与趋势图

- 全局标题栏左侧展示“概览中心”，右侧只保留全屏按钮；移除日期选择器及右下角悬浮全屏入口。
- 保留右栏资产区与服务区 60:40 的高度关系；资产区内部改为“标题 + 自适应 2×2 网格”，四个资产卡纵向撑满可用空间，不保留底部空白。
- 帮助中心链接与需求反馈按钮使用同一套入口样式：相同的 Flex 布局、图标尺寸、文字位置、背景和交互状态；仅点击行为不同。
- 累计运行取数时长图保留卡片 24px 内边距；图表 Grid 子项允许收缩，画布宽度不得超过内容区，左右和底部均不得越出卡片。

### 本轮验收数据

- 1963px 视口下，资产网格底部与资产区内容底部的剩余间距不超过 18px。
- 两个服务入口的盒模型、对齐方式和可见尺寸一致。
- 趋势图画布右边界不超过趋势卡内容区右边界，允许 1px 渲染误差。

## 批注收口：移除日期选择器

- 删除标题栏日期选择器，不改变当前页面指标的固定周期口径。
- 删除日期切换、清空日期、切换加载等仅由选择器触发的交互入口；当前指标、趋势和热力图继续使用现有默认周期数据。
- 全屏按钮迁入标题栏右侧，使用现有进入/退出全屏逻辑和 Tooltip；页面右下角不再出现悬浮按钮。
- 验收时标题栏只包含“概览中心”和一个全屏按钮，DOM 中不存在日期选择器，且全屏按钮的计算样式不是 `position: fixed`。
