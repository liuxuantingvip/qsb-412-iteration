# 概览页 Mock 与机器人工具栏设计

## 目标

收口概览页的数据异常、公告和机器人视图批注：补齐严谨且足量的 mock 数据，修正数据异常区域对齐，并统一工具栏与标题样式。

## 数据异常 Mock

- 四个异常 Tab 每个提供 20 条，共 80 条。
- 使用 20 个不同店铺名，每个异常环节分别配置符合该环节的异常类型和原因。
- `runRecordKey` 按异常环节和序号生成，80 条全局唯一。
- 异常类型与原因必须语义一致：登录异常不使用入库原因，入库校验异常不使用账号原因。
- 列表在数据异常板块内部滚动，Tab 表头保留在可见区。

## 公告 Mock

- 公告列表提供 10 条标题不重复的业务公告。
- 源数据使用 `YYYY-MM-DD` ISO 日期，界面统一显示为 `MM/DD`。
- 公告按发布日期从新到旧排列。
- 公告列表在公告板块内部滚动，标题栏和“更多”入口保持可见。

## 数据异常板块对齐

- 数据异常率概览、分隔线和 Tab 详情从板块顶部对齐，不再垂直居中。
- 概览区保留指标、异常数据表数和环比文案，不改变数值口径。
- 分隔线随板块内容区高度延展，详情列表使用剩余高度。

## 机器人工具栏与标题

- 视图切换默认选中机器人按钮，网格按钮不选中。
- 超限提示位于工具栏整行最右侧。
- 全屏按钮从排期容器右上角移入“机器人”固定列表头，放在标题文字旁边。
- 全屏目标仍为机器人排期容器，普通态和全屏态均可通过该按钮切换。
- “资源中心”标题字号从 14px 调整为 16px，与其他板块二级标题一致，所有断点使用同一字号。

## 验收

- 四个异常 Tab 每个恰好 20 条，80 个 `runRecordKey` 全局唯一。
- 异常列表切换、内部滚动、重试和查看入口可用。
- 10 条公告标题不重复，日期倒序且显示为 `MM/DD`。
- 数据异常概览与 Tab 详情顶部对齐。
- 机器人按钮默认选中，超限提示在工具栏最右侧，全屏按钮位于“机器人”表头旁。
- “资源中心”标题计算字号为 16px。
- `npm run test:etl` 和 `npm run build` 通过，5178 真页无新增控制台错误。
