# 个人中心与开放平台导航设计

## 背景与目标

当前右上角用户菜单仅包含“个人中心”和“退出登录”，下拉宽度与用户触发区未对齐；个人中心侧栏也只提供“账号设置”和“API Keys”。本次在 412 需求原型中补齐个人中心与开放平台的信息架构，并保持现有页面和 mock 边界。

## 导航结构

右上角用户菜单固定包含：

1. 个人中心
2. 开放平台
3. 退出登录

点击“个人中心”后，左侧菜单展示：

1. 账号设置
2. 连接器管理
3. 存储管理
4. 短信队列管理
5. 机器人设备管理

点击“开放平台”后，左侧菜单展示：

1. API Keys
2. MCP 服务
3. 回调服务

首次进入个人中心默认打开“账号设置”；首次进入开放平台默认打开“API Keys”。“退出登录”保留为菜单操作，本期不新增真实退出接口。

## 页面内容

“账号设置”沿用现有个人信息页，覆盖头像、用户名、有效期、云资源、连接器信息和修改密码入口。现有成熟页面继续复用；尚无完整业务内容的新增入口使用统一空状态，避免虚构生产能力。

## 视觉与交互

用户下拉菜单的宽度与右上角用户触发区一致，左右边缘对齐；菜单项保持单行展示。切换“个人中心”和“开放平台”时更新左侧菜单、默认选中项和主内容，不改变当前需求、PRD/交互原型切换状态。

## 实现边界

- 仅修改当前 `5178` 对应的 `412 迭代需求文件`。
- 不修改 411 相邻副本、生产子应用或后端接口。
- 不为占位页面新增 mock CRUD、持久化或鉴权逻辑。
- 同步修正相关 PRD 中“开发平台”的旧称和入口路径。

## 验收标准

1. 用户下拉菜单显示“个人中心 / 开放平台 / 退出登录”。
2. 下拉菜单与用户触发区等宽且左右对齐。
3. 点击“个人中心”后展示五个指定侧栏入口，默认进入“账号设置”。
4. 点击“开放平台”后展示三个指定侧栏入口，默认进入“API Keys”。
5. 各侧栏入口均可点击并显示对应页面或统一空状态。
6. 账号设置页可见头像、用户名、有效期、云资源、连接器与修改密码入口。
7. 412 工程构建通过，`5178` 真页无新增控制台错误。
