# 概览交互标注补全设计

## 目标

为“优化取数宝概况”原型补齐面向研发、测试评审的交互标注。标注只解释页面无法直接表达的业务规则、状态联动、边界条件、失败恢复和跨页面去向，不重复控件名称或可见文案。

标注内容与现有 PRD 的“用户场景与交互说明”逐项映射，不改变概览原型的产品结构、业务口径和 PRD 模板。

## 标注结构

新增概览专属标注数据与抽屉，复用现有通用标注组件。标注按三个页面分组，共 10 条：

1. 账户与服务：3 条。
2. 运行趋势：5 条。
3. 数据完成与异常：2 条。

编号使用 `1.1`、`1.2`、`2.1` 两级结构；稳定标识使用 `QSB-1.1` 至 `QSB-3.2`。页面上的标注目标使用相同稳定标识，定位时滚动到真实 UI 对象并高亮。

## 标注清单

### 1. 账户与服务

#### 1.1 账户价值

- UI 对象：累计节省人力及计算说明入口。
- 标记位置：账户价值卡的“累计节省人力”区域。
- 隐藏规则：累计节省人力由成功执行计划的标准人工时长合计除以 480 分钟/天计算；说明浮层展示当前计算依据；续期是已有业务入口，不在概览内完成续费流程。
- PRD 映射：账户价值。
- 验收：数值、计算说明和到期时间口径一致；计算说明支持鼠标悬浮和键盘聚焦。

#### 1.2 我的资产

- UI 对象：店铺、连接器、云桌面、机器人资产卡。
- 标记位置：“我的资产”卡片标题与资产列表整体。
- 隐藏规则：四类资产均展示已使用量/总量；概览只提供查看与增购入口，不承担分配、释放、规格变更和连接配置。
- PRD 映射：我的资产。
- 验收：四类资产均有分子和分母；增购不被描述为概览内配置能力。

#### 1.3 公告与资源入口

- UI 对象：公告列表、更多、帮助文档和 SLA 服务手册。
- 标记位置：公告卡片与资源中心标题区共用同一标识，按联合范围定位。
- 隐藏规则：公告按发布日期倒序；点击公告打开消息中心对应公告并更新已读；点击更多打开公告分类；资源链接在新窗口打开。
- PRD 映射：公告与资源中心。
- 验收：公告、更多和两个资源入口去向正确；公告打开后在当前页面会话中保持已读状态。

### 2. 运行趋势

#### 2.1 周期指标与联动

- UI 对象：昨日、周、月及四项运行指标。
- 标记位置：周期 Tab 与运行指标区域整体。
- 隐藏规则：只支持昨日、周、月；切换后四项指标、同期文案、机器人排期和运行数据趋势使用同一周期；计划运行次数等于入库成功次数加取数失败次数。
- PRD 映射：周期运行指标。
- 验收：任一周期切换后各区域同步刷新，指标可相互核对。

#### 2.2 视图切换

- UI 对象：机器人视图与运行数据视图切换按钮。
- 标记位置：两个视图按钮整体。
- 隐藏规则：默认机器人视图；切换不改变顶部周期；机器人视图展示排期规则，运行数据视图展示趋势规则；选中态支持辅助技术读取。
- PRD 映射：机器人排期、运行数据视图。
- 验收：两个视图互斥选中，周期保持不变，视图专属工具和图例不串场。

#### 2.3 排期导航与全屏

- UI 对象：前后周期按钮、当前周期标题和全屏按钮。
- 标记位置：排期导航区与全屏按钮共用同一标识，按联合范围定位。
- 隐藏规则：昨日按日、周按 7 天、月按自然月切换；禁止进入未来允许范围；全屏只作用于机器人排期容器；Esc 退出后按钮状态同步。
- PRD 映射：排期导航与全屏。
- 验收：达到最晚周期时下一周期禁用；进入与退出全屏不改变周期和视图数据。

#### 2.4 计划卡片与完整详情

- UI 对象：机器人排期中的代表性计划卡片。
- 标记位置：第一张可见计划卡片，避免给每张重复标记。
- 隐藏规则：卡片高度小于 44px 时单行展示并省略；达到 44px 时展示计划名称和时间/耗时两行，超出继续省略；悬浮或键盘聚焦显示完整计划名、运行次数、最新结果、失败错误码、涉及店铺和涉及入库表。
- PRD 映射：机器人排期、计划卡片与详情。
- 验收：两种高度策略正确；省略内容始终可通过 Tooltip 完整查看；月视图保持现有排期结构。

#### 2.5 运行数据趋势

- UI 对象：运行数据视图及四条趋势图例。
- 标记位置：运行数据图表容器。
- 隐藏规则：按当前周期展示总运行、取数失败、重试和入库成功四条趋势；切入该视图后不展示机器人超限提示、计划周期图例、排期导航和全屏按钮。
- PRD 映射：运行数据视图。
- 状态定位：从标注抽屉点击定位时，自动切换到运行数据视图后再高亮图表。
- 验收：图例、曲线与顶部周期一致；机器人视图专属元素不残留。

### 3. 数据完成与异常

#### 3.1 完成率与异常率口径

- UI 对象：数据完成率和数据异常率指标区。
- 标记位置：两个指标整体。
- 隐藏规则：完成率由完成数据表/总数据表计算；异常率由异常数据表/总数据表计算；百分比、分子、分母和同期变化必须来自同一事实周期。
- PRD 映射：数据完成与异常。
- 验收：两个百分比均可由页面分子、分母复算，趋势方向不只依赖颜色表达。

#### 3.2 异常分类与处置

- UI 对象：异常分类 Tab、异常明细、重试和查看入口。
- 标记位置：异常明细区域整体；操作规则标记在第一行代表性操作入口，不逐行重复。
- 隐藏规则：异常分为登录异常、取数执行异常、入库异常、入库校验异常；重试只提交当前异常记录，提交中禁用重复操作，成功提示“已提交重试”，失败保留当前分类和明细；查看进入运行记录并携带日期、异常环节、计划、店铺和目标运行记录，自动打开对应详情。
- PRD 映射：异常明细与处置。
- 验收：四类异常可切换；重试成功和失败均有明确状态；查看后的筛选条件和目标详情正确。

## 定位与状态恢复

- 普通标注直接定位当前页面上的真实对象。
- 运行数据趋势标注需要先切换到运行数据视图，再执行定位和高亮。
- 计划卡片标注需要确保机器人视图和至少一张代表性计划卡片可见。
- 定位行为只改变展示所需的当前视图，不修改业务数据，不伪造不存在的计划或异常记录。
- 同一规则覆盖多个紧邻对象时允许复用标识并使用联合矩形高亮；其他标注在同一页面只出现一次。

## 交互标注入口

- 概览需求激活时，顶部入口从“交互标注 0”变为“交互标注 10”。
- 点击后打开现有右侧标注抽屉，支持全部和三个页面分组筛选。
- 每条标注保留“定位”动作；关闭抽屉不改变概览当前周期、视图和异常分类。
- PRD 视图不展示标注目标；标注入口仍按现有需求壳层规则处理。

## 代码边界

- 新增概览专属 annotation data 与薄封装组件。
- 在 `App.tsx` 接入概览标注列表、抽屉和定位事件。
- 在概览页面为 10 个真实 UI 对象增加标记或 `data-note-id`，不改变原业务结构。
- PRD 内容不重写；只在测试中校验 10 条标注与现有场景名称保持映射。
- 不修改其他需求的标注数据、抽屉和定位行为。

## 验证

- 标注数据测试：数量、编号、稳定标识、页面分组、PRD 映射和关键规则完整。
- 标记测试：每条稳定标识均存在真实页面目标；需要状态切换的标注具有对应定位事件。
- 运行 `validate_annotations.py` 检查缺失、重复和格式问题；重复标识仅允许设计中声明的联合定位对象。
- 运行项目测试、构建和 `git diff --check`。
- 在 5178 真页检查入口数量、抽屉分组、10 条文案、逐条定位、运行数据视图自动切换、联合高亮和控制台错误。

## 非目标

- 不给所有可见按钮逐个添加标注。
- 不把 PRD 段落复制到标注卡片。
- 不新增生产接口、持久化、权限或真实失败模拟。
- 不通过标注修补错误 UI；若真页与已确认产品规则冲突，先修原型或回到需求确认。
