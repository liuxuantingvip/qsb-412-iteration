# 概览交互标注业务契约设计

## 目标

将“优化取数宝概况”的 10 条交互标注升级为研发可实现、测试可直接编写用例的业务/UI 契约。标注只定义字段、状态、动作、反馈、恢复和验收结果，不解释页面数据文件或技术实现。

## 统一结构

### 数据展示类

1. 字段定义：字段名、业务含义、业务数据来源、公式或枚举、格式与单位。
2. 状态与边界：加载、空值、事实值 0、失败、无权限、超长和未知枚举。
3. 交互与反馈：用户触发方式、状态表达和即时反馈。
4. 恢复与跳转：失败恢复、刷新条件和跨页面参数。
5. 验收：输入条件和可观察结果均使用确定句。

### 操作类

1. 触发条件与系统响应。
2. 状态与边界。
3. loading、禁用、成功与失败反馈。
4. 恢复动作或跳转参数。
5. 验收。

所有标注复用 `ruleItems`、`exceptionItems`、`stateItems`、`recoveryItems` 和 `acceptanceItems`，优先使用短列表与嵌套子项。禁止在用户可见标注中出现“当前页面值”“原型”“mock”“overviewContent.ts”“生产接口待确认”等解释，也不得重复页面可见文案代替规则。

### 样式预览原则

- 字段来源、计算公式、权限条件和跳转参数用文字说明。
- 状态枚举、空值、异常提示、按钮 loading/禁用、成功与失败反馈属于视觉验收对象，直接复用页面现有样式或对应 Arco 组件；缺省场景使用 Arco Empty，不用纯文字或 Alert 冒充缺省页。
- 同一规则同时包含业务判断和视觉结果时，文字说明判断条件，预览展示最终样式；不得只写“绿色标签”“失败提示”等让研发自行猜测的描述。
- 仅在样式影响研发实现或测试验收时增加预览，不为普通说明文字机械添加组件。

## 逐条内容范围

### QSB-1.1 个人信息板块

- 字段定义：租户名称来自当前登录租户 `tenantName`，示例为“森森科技有限公司”；服务版本来自当前租户产品服务版本。自用版定义为客户自行配置并处理日常异常，使用绿色标签；全托版定义为平台交付团队代配置、监控和处置，使用蓝色标签；未知枚举显示“--”。累计节省人力来自成功执行计划对应标准人工时长累计，按分钟数除以 480 并保留 1 位小数。到期时间来自当前有效产品授权结束日期，普通授权显示 `YYYY-MM-DD`，永久授权显示“长期有效”。
- 状态与边界：加载显示骨架；租户名超长单行省略并提供 Tooltip；事实值 0 显示 0.0 天，取数失败显示“--”；无到期值显示“--”；无权限显示“无权限查看”。
- 交互与恢复：说明入口支持 hover 和 focus；仅存在可续期授权时展示续期，携带租户 ID 与授权 ID 进入续期流程。
- 定位：`target` 为空，不显示副标题；`QSB-1.1` 唯一 marker 放在个人信息整卡。

### QSB-1.2 我的资产板块

- 字段定义：店铺、连接器、云桌面、机器人分别定义已使用量和总量的业务来源，统一按 `used/total` 展示。
- 状态与边界：未购买显示 `0/0`，查询失败显示 `--/--`；`used > total` 保留原值并标异常；覆盖加载和无权限。
- 操作与恢复：点击增购在新窗口打开前端固定维护的钉钉商务会话 URL；四类资产共用该地址，不携带租户、资产类型和数量参数，不进入站内下单或支付流程。外部窗口未打开时保留概览，允许再次点击；返回后不自动刷新资产。

### QSB-1.3 公告与资源中心

- 字段定义：公告来自后台管理-公告管理中状态为已发布，且发送范围为全部租户或电商取数宝的记录；标题取公告标题、日期取发布时间，并按发布时间倒序。帮助文档固定为 `https://help.shizai.com/`，SLA 服务手册固定为 `https://help.shizai.com/sla`，名称与地址均由前端固定维护。
- 状态与边界：标题不按固定字数截断；可用宽度为列表行宽度减日期实际宽度和 12px 间距，渲染宽度超出时才单行省略并提供 Tooltip，容器变化后重新计算。加载显示列表骨架；空数据使用 Arco Empty；失败使用缺省页并提供明确的重试按钮。
- 操作与恢复：公告详情打开成功后标记已读；更多进入公告分类；帮助文档和 SLA 在新窗口打开；打开失败不改变当前页状态。

### QSB-2.1 周期与运行指标

- 字段定义：所有时间按 `Asia/Shanghai` 计算，分别定义昨日、连续 7 天和自然月的时间范围及紧邻上一周期。计划运行、入库成功、入库数据量和取数失败分别定义记录来源、格式和单位，并满足 `planRuns = ingestSuccess + collectFailure`。
- 状态与边界：事实值 0 与无数据“--”分开；覆盖无权限和等式不一致。
- 操作与恢复：切换期间 loading 并防重复，成功后指标、排期和趋势使用同一周期；失败回退原周期及原数据并提供重试。

### QSB-2.2 运行视图切换

- 触发与响应：默认机器人视图；切换时保留周期。机器人视图显示排期导航、图例、超限提示和全屏；运行数据视图显示趋势、图例和 Tooltip。
- 状态与边界：两个按钮互斥；选中态使用 `aria-pressed`；无权限或重复点击不发起无效切换。
- 反馈与恢复：切换期间 loading 并禁用；加载失败回退原视图、保留周期并提供重试。

### QSB-2.3 排期导航与全屏

- 触发与响应：昨日按单日、周按 7 天、月按自然月导航；下一周期不得超过最晚周期。全屏只作用于机器人排期容器，Esc 与退出按钮同步状态。
- 状态与边界：最晚周期下一按钮禁用；运行数据视图不展示导航与全屏；覆盖 Fullscreen API 不支持、拒绝和无权限。
- 反馈与恢复：周期和全屏请求期间 loading 并禁重复；周期失败保留原周期，全屏失败保留非全屏状态；退出全屏不重置周期和滚动位置。

### QSB-2.4 计划卡片

- 字段定义：计划名称、起止时间、耗时、运行次数、最新结果、错误码、涉及店铺、涉及入库表均定义业务含义。
- 状态与边界：高度小于 44px 时单行省略，大于等于 44px 时双行省略；空错误码、店铺或入库表显示“--”；成功和失败同时使用文字与图形状态。
- 交互与恢复：hover 与 focus 打开同一 Tooltip，卡片可通过键盘到达；详情失败时保留基础信息并允许重试。

### QSB-2.5 运行数据趋势

- 字段定义：总运行、取数失败、重试、入库成功分别按运行事实聚合；昨日按小时、周按天、自然月按天，与 QSB-2.1 使用同一周期。
- 状态与边界：覆盖加载、空、部分失败、全部失败和无权限；缺失事实点不连线、不补 0。
- 交互与恢复：图例控制序列显隐，Tooltip 展示同一时间桶事实；失败后保留周期并重试，成功后不重置图例选择。

### QSB-3.1 完成率与异常率

- 字段定义：完成率为完成数据表除以总数据表，异常率为异常数据表除以总数据表，均保留 1 位小数。两项同比均使用去年同一时间范围；同比 =（本期比率 ÷ 去年同期比率 − 1）× 100%，以未舍入比率计算后保留 1 位小数，单位为 %。同期比率为 0、同期数据缺失或同期总表数为 0 时显示“--”。
- 状态与边界：分母为 0 显示“--”；覆盖分子大于分母、对比数据缺失、加载、失败和无权限。
- 反馈与恢复：趋势同时使用数值、颜色和箭头；单项失败不覆盖另一项，重试成功后同步刷新比率、分子分母和变化值。

### QSB-3.2 异常明细与处置

- 字段定义：登录异常、取数执行异常、入库异常、入库校验异常分别映射登录/授权、取数执行、入库写入、入库校验阶段。四类列表都在店铺后单独展示计划名称列，随后为异常类型、原因和重试/查看。计划取所属 Work 的计划名称；发生时间和运行记录 ID 来自同一记录。
- 状态与边界：覆盖加载、空、失败、查看权限、处置权限、不可重试、超长字段和缺少运行记录 ID。
- 操作与恢复：重试只提交当前异常记录所属 Work。失败提示“{计划名称} 计划重试失败，已更新该异常数据”，保留行并更新本次异常；成功提示“{计划名称} 计划重试成功，该异常即将从列表移除（6s）”，逐秒倒计时，6秒后移除该行及反馈。提交及成功倒计时期间禁止重复重试。两种结果均提供“查看运行记录”，直接打开本次新记录详情，不使用旧记录替代；缺少新记录 ID 时禁用。查看详情不暂停倒计时，行移除后已打开详情保持可读；保留分类及滚动位置。

## 定位与状态恢复

- 普通标注直接定位已存在的 UI 对象。
- QSB-1.1、QSB-1.2 分别框选完整个人信息卡、资产卡；高亮线绘制在卡片内部，避免被卡片裁切。QSB-1.3 仅定位完整公告卡片，不将资源中心合并进定位范围。
- 机器人超限提示仅在机器人视图且当前排期周期至少一台机器人超限时显示；全部未超限、空列表、状态未返回及运行数据视图均隐藏。沿用排期超限判定，不以计划数或排序推断，不新增数值阈值；机器人标签和顶部提示共用同一状态。
- 异常行可点击的“重试 / 查看”文字使用产品主色；正文灰色只作用于明细字段，不覆盖按钮内部文字。
- QSB-2.3 和 QSB-2.4 定位前切换为机器人视图；QSB-2.5 定位前切换为运行数据视图。
- 定位行为只改变展示所需视图，不修改业务数据。
- 同一规则覆盖多个紧邻对象时允许复用标识并联合高亮；QSB-1.1 只在个人信息整卡出现一次。

## 代码边界

- 标注数据只描述业务/UI 契约，通用抽屉继续负责结构化列表渲染。
- 个人信息板块空 `target` 时不渲染副标题。
- PRD 保持既有章节和版式，只将“账户价值”场景改为“个人信息板块”并同步 QSB-1.1 关键定义。
- 不修改其他需求的标注、抽屉和定位行为。

## 验证

- 表驱动校验 10 条标题、分组、结构化字段和定位事件。
- 逐条校验关键字段、状态、反馈、恢复和验收覆盖，并扫描禁止措辞。
- 校验空 `target` 条件渲染、QSB-1.1 整卡唯一 marker 和 PRD 模板局部同步。
- 运行 `npm run test:etl`、`npm run build` 和 `git diff --check`。
