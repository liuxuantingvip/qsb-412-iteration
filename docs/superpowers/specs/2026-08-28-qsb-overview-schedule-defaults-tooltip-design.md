# 概况排期默认状态与 Tooltip 设计

## 目标

统一概况排期的默认状态、视图入口顺序、日周任务卡片间距，以及日/周/月共享的计划悬浮信息。

## 默认状态

- 运行趋势默认选中“月”。
- 排期默认使用“机器人视图”。
- 视图切换顺序为“机器人视图、运行数据视图”。

## 任务卡片

- 日、周时间日历中的计划卡片使用 `padding: 4px`。
- 月历保持当前紧凑展示，不额外放大格子内任务项。

## Tooltip 字段

字段顺序固定为：

1. 计划名称。
2. 运行次数：`x 次`。
3. 最新结果：成功显示“入库成功”；失败显示“失败（错误码）”。
4. 涉及店铺（x）：完整展示全部店铺名称，支持换行与超高滚动。
5. 涉及入库表：完整展示全部表名，支持换行与超高滚动。

## 数据模型

在排期 block 上补充最新 work 结果、错误码和入库表集合。日、周、月继续共用同一任务内容组件和 Tooltip 组件；mock 数据保持确定性，便于测试和真页验收。

## 验收

- 首次进入页面时“月”和“机器人视图”处于选中状态。
- 机器人视图按钮在运行数据视图之前。
- 周视图计划卡片计算样式为四向 `4px` 内边距。
- 成功、失败 Tooltip 文案符合字段顺序，失败项带错误码。
- 至少一个计划完整展示多店铺和多张入库表。
