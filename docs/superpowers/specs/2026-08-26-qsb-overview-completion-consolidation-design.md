# 概览中心完成率收口设计

## 目标

让页面只保留两条主线：先看运行趋势与机器人排期，再看数据完成情况及异常明细。

## 页面结构

1. 删除独立的“数据概况”卡片。
2. 删除该卡片中的“今日涉及店铺”和“平台交付分布”。
3. 将原“数据异常率”卡片改名为“数据完成率”。
4. 合并后的卡片左侧展示：
   - 数据完成率；
   - 完成数据表数量；
   - 数据异常率；
   - 异常数据表数量与环比。
5. 卡片右侧保留登录异常、取数执行异常、入库异常、入库校验异常四个 Tab 及明细。
6. “运行趋势”卡片高度由 530px 增至 720px，新增空间全部用于排期或数据视图；横向与纵向滚动能力保持不变。

## 约束

- 不新增业务指标或解释文案。
- 不改变异常重试、查看、公告、资源中心和周期切换交互。
- 不修改生产前端，仅修改 412 `qsbOverview` 原型与对应测试。

## 验收

- 页面中不再出现“数据概况”“今日涉及店铺”“平台交付分布”。
- 主内容区只包含“运行趋势”和“数据完成率”两张卡片。
- “数据完成率”卡片同时可见完成率、异常率、异常 Tab 和明细。
- 运行趋势卡片高度为 720px，排期视图仍可横向和纵向滚动。
