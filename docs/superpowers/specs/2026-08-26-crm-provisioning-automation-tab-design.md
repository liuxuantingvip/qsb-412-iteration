# CRM 自动化开通需求 Tab 设计

## 目标

在取数宝 412 迭代原型的需求切换区新增“CRM 自动化开通”Tab，作为后续拉齐需求的独立入口。

## 范围

- 新增需求 Key：`crmProvisioningAutomation`。
- 新增 Tab 名称：“CRM 自动化开通”。
- Tab 排在当前需求列表末尾。
- PRD 视图和交互原型视图均显示“需求待拉齐”空状态。
- URL 支持 `?requirement=crmProvisioningAutomation&tab=prd|prototype`。

## 本次不做

- 不编写 CRM 提单、审批、开通或回写流程。
- 不设计字段、状态机、权限、异常处理和埋点。
- 不调用 CRM、取数宝后台或云电脑真实接口。
- 不改动生产取数宝前后端。

## 交互与降级

- 点击 Tab 后保持现有 PRD／交互原型切换方式。
- 空状态不展示推测性业务内容，避免把未拉齐方案当成已确认需求。
- 交互标注入口保持禁用，直到后续真正增加标注。

## 验收标准

- 412 顶部可见“CRM 自动化开通”Tab，且顺序在现有需求之后。
- 点击后 URL 中的 requirement 参数正确。
- PRD 与交互原型均只显示“需求待拉齐”空状态，不误入已有需求页。
- 需求注册测试、构建和 diff check 通过。
