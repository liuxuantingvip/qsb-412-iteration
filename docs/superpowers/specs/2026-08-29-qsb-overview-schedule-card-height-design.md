# 排期阶段卡片高度自适应设计

## 目标

机器人日/周时间排期中的阶段卡片根据实际显示高度切换信息密度，避免短任务卡片强行展示两行而发生拥挤或溢出。

## 展示规则

- 卡片实际高度小于 `44px` 时，阶段名、时间范围和耗时合并为一行，超出卡片宽度后显示省略号。
- 卡片实际高度大于或等于 `44px` 时，第一行展示阶段名，第二行展示时间范围和耗时；两行分别限制为单行并在超出宽度后显示省略号。
- 完整任务信息继续通过现有悬浮 Tooltip 展示。

## 实现边界

- 仅调整机器人日/周时间排期卡片。
- 不调整月视图、数据视图、任务 Mock、时间刻度和 Tooltip 内容。
- 高度判断使用卡片渲染高度，与当前每小时 `40px` 的时间刻度保持一致。

## 验收标准

- 55 分钟任务卡片约为 `36.7px`，只展示一行且内容不溢出。
- 高度达到 `44px` 的任务卡片展示两行且内容不溢出。
- 窄卡片中的长阶段名能够省略，键盘聚焦和悬浮 Tooltip 行为保持不变。
