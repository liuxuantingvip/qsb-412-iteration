# 概览周期数据与 IconPark 图标设计

## 目标

- “每日 / 每周 / 累计”切换时，四个运行指标和比较文案同步变化。
- 机器人 24 小时排期保持当天视图，不随统计周期切换。
- “我的资产”和“资源中心”使用 IconPark 官方 React 图标，保持现有布局与文案。

## 周期 mock

| 周期 | 计划运行次数 | 入库成功次数 | 入库数据量 | 取数失败次数 | 比较口径 |
| --- | ---: | ---: | ---: | ---: | --- |
| 每日 | 28,755 次 | 27,248 次 | 15.54 亿条 | 1,507 次 | 较昨日 |
| 每周 | 187,960 次 | 178,340 次 | 102.68 亿条 | 9,620 次 | 较上周 |
| 累计 | 8,642,310 次 | 8,126,440 次 | 4,782.16 亿条 | 515,870 次 | 较上期 |

每个周期直接维护一套 mock，不在运行时通过倍数推导。涨跌值作为该周期 mock 的一部分，切换后与指标一起更新。

## 图标

使用 `@icon-park/react` 官方包按需引入，统一 `theme="outline"`、`size={16}` 或 `size={24}`、`fill="currentColor"`。资产图标使用店铺、连接、云端、机器人语义图标；资源中心使用帮助文档和服务手册语义图标。只替换现有 Arco 图标，不改变组件尺寸、间距和交互。

## 验收

- 三个周期分别显示对应指标、比较口径和涨跌信息。
- 切换周期不改变机器人 24 小时排期。
- 资产与资源中心不再引用 Arco 图标。
- `npm run test:etl` 与 `npm run build` 通过。
- 5178 真页切换周期可见数据变化，图标无错位、控制台无新增错误。
