# 概况日历导航边界与 Tooltip 自适应设计

## 目标

- Tooltip 宽度随内容扩展，在视口边界内完整换行，不截断店铺或入库表。
- 日历不允许导航到今天之后的日期或周期。
- 删除运行趋势标题旁的更新时间说明。

## 日期边界

原型业务“今天”固定为 `2026-08-28`，保证 mock 页面和自动化验收稳定。

- 日视图：最晚为 `2026-08-27`，当天及未来不可选。
- 周视图：当前周可查看，不能进入下一周。
- 月视图：当前月可查看，不能进入下一月。
- 达到边界时“下一个周期”按钮禁用，处理函数同时拒绝越界，避免只依赖按钮状态。

## Tooltip

- 内容区使用 `width: max-content`。
- 最大宽度限制为视口减去安全边距。
- 店铺和入库表取消固定高度及滚动裁剪，允许完整换行。

## 验收

- 多店铺、多入库表 Tooltip 无横向溢出或内容截断。
- 日、周、月边界按钮状态正确，且不能越界。
- 页面不再出现“更新时间”文案。
