# 门户操作日志设计

## 背景与目标

租户管理员目前缺少统一入口，无法追溯本租户成员在取数宝门户以及通过 API、MCP 发起的操作。本需求在「个人中心」新增操作日志，帮助租户管理员定位误操作、调用失败和关键配置变更，同时保证租户隔离和敏感信息安全。

## 用户与权限

- 使用者为租户管理员，普通租户成员不展示入口。
- 租户管理员只能查询、查看和导出当前租户的日志，禁止跨租户访问。
- 日志不可编辑、不可手动删除，保留 180 天，到期后由系统自动清理。
- 成员被删除或凭证被撤销后，历史日志仍保留操作发生时的成员名称、成员标识、凭证名称和凭证标识快照。

## 产品入口与信息架构

- 入口：`个人中心 / 操作日志`。
- 页面包含三个 Tab：`门户操作`、`API`、`MCP`。
- 三个 Tab 共用查询、列表、详情和导出框架，API、MCP 在公共字段之外增加凭证名称。
- 页面默认查询近 7 天；单次查询时间跨度不超过 90 天。

## 记录范围

### 门户操作

记录租户成员在取数宝前台主动发起、且实际请求到达服务端的业务操作，包括：

- 新增、修改、删除、启用、停用；
- 执行、重试、导入、导出；
- 授权及其他会改变业务数据、安全状态或任务状态的操作。

成功和失败均记录。用户取消、仅触发前端校验且未发出请求、字段值未实际变化时不生成日志。

以下浏览行为不记录：进入页面、查看详情、搜索、筛选、切换 Tab。

### API 与 MCP

- 记录可归属到当前租户成员及其凭证的 API、MCP 调用，包括成功和失败调用。
- API、MCP 调用按凭证绑定成员识别操作者，并保存凭证名称快照。
- Token、API Key、密码、Cookie、密钥和完整敏感参数不得写入日志。

### 不记录范围

系统定时任务、自动重试、自动推送及其他无法归属到租户成员或其凭证的自动行为，不在本页面展示。

## 页面设计

### 筛选

三个 Tab 均支持：

- 时间范围；
- 操作者；
- 功能模块；
- 操作类型。

API、MCP Tab 额外支持按凭证名称筛选。操作内容和操作结果只用于列表展示，不作为筛选条件。

### 操作类型

统一取值为：新增、修改、删除、启用、停用、执行、重试、导入、导出、授权、其他。

### 列表

列表默认按操作时间倒序并支持分页，展示：

- 操作时间；
- 操作者；
- 功能模块；
- 操作类型；
- 操作内容；
- 操作结果；
- IP 地址。

API、MCP Tab 额外展示凭证名称。操作结果统一为成功、失败，并使用状态标签区分。

### 日志详情

点击列表行打开详情抽屉，展示：

- 列表中的基础信息；
- API、MCP 的凭证名称；
- 失败操作的失败原因；
- 编辑类操作实际发生变化的字段、变更前和变更后；
- 经过脱敏的请求信息。

手机号等个人信息按既有安全规则脱敏；Token、API Key、密码、Cookie、密钥和完整敏感参数不展示。

### 导出

- 租户管理员可以按当前 Tab、时间范围及筛选条件导出日志。
- 导出文件只能包含当前租户数据，并沿用页面脱敏规则。
- 发起导出本身作为一条门户操作记录；导出成功和失败均记录。

## 日志生成与数据流

1. 租户成员通过门户、API 或 MCP 发起操作。
2. 服务端完成身份、租户和凭证校验，执行对应业务请求。
3. 请求结束后，服务端依据实际结果生成成功或失败日志；编辑类操作只保存实际变化字段。
4. 日志保存操作者、租户、来源类型、功能模块、操作类型、内容摘要、结果、失败原因、IP、凭证快照和发生时间。
5. 租户管理员查询时，服务端必须基于当前登录租户强制限定数据范围，不能接受前端传入其他租户作为查询依据。

日志写入不阻断原业务操作。写入失败时进入服务端告警和补偿机制，不能向用户返回“业务操作失败”的错误结论。

## 异常与空状态

- 查询失败：不展示旧数据或虚构内容，显示失败状态和“重新加载”。
- 无数据：根据当前 Tab 和筛选条件显示对应空状态。
- 详情缺失：显示“详情暂不可用”，不影响列表继续使用。
- 导出失败：展示可读失败原因并允许重试，失败请求仍生成门户操作日志。
- 时间跨度超过 90 天：阻止查询并提示缩短时间范围。
- 无权限或租户身份失效：禁止展示日志并给出明确权限提示。

## 本期不做

- 不向普通租户成员开放日志入口。
- 不支持用户编辑、删除或调整日志保留周期。
- 不记录门户浏览行为。
- 不展示系统自动任务日志。
- 不提供跨租户查询和导出。
- 不新增操作内容、操作结果筛选。

## 验收标准

- 仅租户管理员可看到「个人中心 / 操作日志」，普通成员无入口且接口访问被拒绝。
- 门户操作、API、MCP 分 Tab 展示，字段、筛选和详情符合本设计。
- 门户关键操作和 API、MCP 调用的成功、失败均正确记录；浏览行为和系统自动行为不产生本页面日志。
- 编辑类操作可查看脱敏后的变更前后值，未变化操作不生成日志。
- API、MCP 日志可追溯成员和凭证名称，凭证撤销后历史快照仍可查看。
- 查询默认近 7 天，单次跨度不超过 90 天；日志保留 180 天且用户不可删除。
- 租户管理员不能通过页面、接口或导出获取其他租户日志。
- 导出结果与当前 Tab、时间范围和筛选条件一致，导出行为本身正确记录。
- 查询失败、详情缺失和导出失败均有明确反馈和恢复入口。
- 页面和导出内容均不泄露 Token、API Key、密码、Cookie、密钥或完整敏感参数。
